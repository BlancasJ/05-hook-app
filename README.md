# 05-hook-app

Collection of reusable custom React hooks: useCounter, useFetch, and useForm.

## Context
- **Course:** Udemy React Course (Fernando Herrera)
- **Date:** 2022

## Tech Stack
- React 18 (hooks)
- Fetch API

## What It Does
Implements three custom hooks as standalone modules. `useCounter` manages a numeric counter with increment, decrement, and reset. `useFetch` handles async data fetching with loading/error states and cleanup via useRef. `useForm` provides controlled form state management with dynamic input handling and reset.
